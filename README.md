# Silicon Empire

A mobile-first smartphone manufacturing tycoon simulator.

## Prototype v0.1.0
- CEO dashboard, company treasury, reputation and R&D progress
- Phone Lab: create smartphone prototypes and launch products
- Chip Lab: tune CPU cores, clock frequency, process node and GPU units
- Factory: expand production capacity, workforce and quality
- R&D Center: research display, camera, battery and SoC technologies
- Market: daily production costs, revenue and sales simulation
- Automatic local save using browser storage

## Visual direction
Premium dark Liquid Glass: translucent layered surfaces, restrained blur, fine borders, soft reflections, graphite tones and cool silver-blue accents. Includes a custom minimal metallic S icon.

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```

This is currently a mobile web prototype. Android APK packaging can be added with Capacitor in a later milestone.
